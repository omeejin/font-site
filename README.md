# 손글씨 폰트 공방

템플릿 이미지에 손글씨를 써서 올리면 **한글 11,172자 · 영문 · 숫자 · 특수기호**가 들어간 TTF 폰트를 만들어 주는 정적 웹사이트입니다.
모든 처리는 브라우저에서 이루어지며 서버가 필요 없습니다(GitHub Pages 등에 그대로 배포 가능).

## 사용 흐름

1. **템플릿 내려받기** – A4 4장 (PNG 다운로드 또는 바로 인쇄)
   - 1–2쪽: 한글 자모 (초성 57 · 중성 21 · 받침 27 · 낱자 자음 19)
   - 3쪽: 숫자 · 영문 대소문자 / 4쪽: ASCII 기호 + 자주 쓰는 특수기호
2. **손글씨 쓰기** – 진한 펜으로 하늘색 영역에 작성
3. **업로드** – 스캔/촬영 이미지를 올리면 페이지를 자동 인식하고 글자를 추출
4. **폰트 생성** – 미리보기 후 `.ttf` 다운로드

## 동작 원리

| 단계 | 파일 | 내용 |
| --- | --- | --- |
| 템플릿 | `js/template.js`, `js/charset.js` | 네 모서리 마커, 페이지 식별 비트, 칸·안내선 렌더링 |
| 인식 | `js/scanner.js` | 마커 검출(연결 요소) → 호모그래피로 원근 보정 → 페이지 비트 판독(회전 자동 판별) → 칸별 샘플링, 조명 보정 |
| 벡터화 | `js/vectorize.js` | 블러·잡티 제거 → 마칭 스퀘어 외곽선 → RDP 단순화 → 구멍/바깥선 판별 |
| 폰트 | `js/fontbuilder.js`, `js/ttf.js` | 2차 베지어 윤곽 생성, 자체 TTF 작성기(glyf/loca/cmap/OS2 등) |

**한글 조합 방식**: 초성은 모음 형태(ㅏ형/ㅗ형/ㅘ형)별로, 중성·받침은 한 번씩 "음절 안의 실제 위치"에 쓰도록 템플릿이 안내합니다.
각 음절은 이 자모 글리프를 겹친 **합성 글리프**(composite glyph)로 만들며, 받침이 있으면 초성·중성을 세로로 압축합니다.
덕분에 124칸만 써도 11,172자 전체가 만들어지고 파일 크기도 약 600KB로 작습니다.

## 로컬 실행

```bash
python3 -m http.server 8123
```

브라우저에서 http://localhost:8123 을 열고, 손글씨가 없다면 **"손글씨 없이 예시로 체험하기"** 버튼으로 전체 과정을 확인할 수 있습니다.

## 테스트

Playwright로 예시 템플릿 → 인식 → 폰트 생성까지 확인하고 `tests/out/demo.ttf`를 저장합니다.

```bash
node tests/e2e.mjs
```

생성된 TTF는 OpenType Sanitizer(OTS)와 fontTools로 검증했습니다.
